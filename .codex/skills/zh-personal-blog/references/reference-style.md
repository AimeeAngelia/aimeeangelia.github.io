# Homulilly 参考样本与目标风格

## 使用边界

以下文章是第一版风格样本。学习它们如何组织真实经历、控制详略和表达判断，不复制原句、专属口头禅、颜文字、ACG 身份设定或作者经历。新文章中的事实和第一人称内容仍只能来自用户材料。

需要为新题材建立声线时，选择最接近的 1 至 2 篇样本阅读即可，不要默认加载全部。若网页暂时不可访问，使用下方已提炼的风格画像。

## 阅读样本时提取什么

只提取与当前文章有关的五项，并在内部使用，不输出模仿分析：

1. 开头从什么具体事情进入；
2. 事实、操作和个人反应各占多少；
3. 哪些内容用段落，哪些交给列表、图片或代码；
4. 作者在哪里直接表达喜欢、不满、犹豫或改变判断；
5. 文章在什么位置自然停止。

不要提取固定词表。相似感应来自信息选择和叙述节奏，不来自重复“略微”“遂”“吃灰”等显眼词语。

## 综合风格画像

### 内容选择

- 文章通常由一件真实发生的小事驱动，而不是由抽象选题驱动。
- 具体日期、价格、版本、报错、用时和失败尝试直接留在正文里。
- 作者只展开自己真正关心或踩坑的部分，不努力覆盖整个主题。
- 技术信息、个人偏好和生活背景可以共存，不必拆成完全不同的文体。

### 叙述节奏

- 很快进入事情本身，背景够用就停。
- 段落长短不均。解释机制时可以连续写，简单评价可以只有一句。
- 小标题帮助查找，不负责制造宏大结构。
- 列表像笔记，不要求每项语法和长度完全平行。
- 后续体验发生变化时直接追加 `Update`，不把历史判断重写得始终正确。

### 人称与判断

- 自然使用“我”，但重点仍是事情、操作和对象。
- 好恶表达直接而低成本，不为每个判断补一套正式论证。
- 幽默来自具体处境、消费反差或失败，不单独制造金句。
- 可以承认记不清、暂时没做完、买错、后悔或改主意。

### 语言与格式

- 书面中文为底，混入适量口语、括号、英文产品名和技术术语。
- 技术内容保留命令、路径、截图和原始错误；兴趣内容允许图片承担大部分信息。
- 删除线、颜文字和网络表达是可选调味，不是每篇必备特征。
- 不追求出版级平滑，清楚且有作者在场即可。

### 结尾

- 技术文章可停在最后一个步骤、限制或外部文档链接。
- 兴趣文章可停在最后一个对象或当下判断。
- 项目文章可停在 TODO 或“先记录到这里”。
- 不补“总结来说”“这次经历让我明白”或面向所有人的价值升华。

## 与 Marginalia 的关系

Homulilly 只提供初始风格参照。后续用户明确修改过、认可并发布到 Marginalia 的文章，才逐渐成为自己的声线证据。除非用户另行要求，本 skill 目前不把仓库内已有文章当作样本。
